# PLAY-POSTURE-MOVEMENT-1: approved bounded configuration contract

Status: user approved on 2026-10-17 in the implementation session (“Yes i approve.”).
Scope and acceptance: [#534](https://github.com/pandasmoon14-hub/Test/issues/534).
Assessed baseline: `20bc39db4dd0d16c9af4ff76033d3f0becf36eb9`.
This decision authorizes this implementation batch, not its merge, general
R4–R6 activation, or canonical anatomy/rules adoption.

AFQR-16 owns the recorded body configuration and pinned embodiment profile.
AFQR-19 separately qualifies configuration changes and movement opportunities;
AFQR-18 retains location/topology; AFQR-01 retains commitment boundaries.
No new semantic owner or universal anatomy substrate is introduced.

The noncanonical humanoid fixture explicitly declares standing, crouching,
kneeling, sitting and lying. Identifiers belong to that versioned profile.
A contrasting nonhumanoid profile can declare different configurations without
inheriting these five. The profile declares which existing fixture places offer
immediate configuration opportunities. There is no inferred floor geometry,
injury, skill, stamina, speed, concealment, facing, healing or action economy.

A configuration request checks actor, profile declaration, current owner digest,
place opportunity and chronology. A real change records one event, preview,
delta and deterministic receipt. An identical current configuration returns a
truthful no-change result. Technical retry of the same command returns its
original receipt; conflicting reuse is refused. Persistent configuration does
not advance WORLD-2, move an entity, or create a maintained bracing task.

Self-inspection projects the recorded own configuration. An absent component
means **unrecorded**, never fictional standing. Unsupported modifiers retain
raw input and do not silently execute a reduced request. Direct and exactly
two-step inputs call the same owner. The terminal saves each changed step before
acknowledging it; first refusal stops the sequence, and earlier committed steps
survive a later refusal. A write failure closes the session without success
acknowledgement.

The Yard east passage, only while the explicitly declared Waystone obstruction
is present, admits the humanoid profile's crouching, kneeling or lying
configuration with the **walk** method. Standing and sitting do not qualify that
clearance. This is one explicit opportunity declaration, not a height/reach or
universal mobility law. Existing crawl licenses remain independent and do not
set lasting posture. The player's lowered clearance cannot transfer to an NPC
through follow intent.

Checkpoint v11 activates on the first real configuration change. It composes
existing owners through their existing replay, plus an AFQR-16 component whose
events pin profile identity, version and complete declaration digest. It checks
actual placement-chain anchors, movement count, actor/place, logical-time bounds,
command identity collisions, and posture-dependent movement evidence and command
fingerprints. Clear-route historical receipts remain unchanged. Legacy histories
without posture retain their old digest and writer; old checkpoints restore
unrecorded. Missing references, altered profile meanings and unsupported mixtures
are rejected rather than migrated by inference.

Deferred: supported body brace/lean, orientation, sprint/pace/time costs,
concealment/detection, jump/climb/swim geometry, general auditory/olfactory input,
generic structural operations, arbitrary NPC compulsion and concurrent planning.
These require their own qualified owner contracts before execution.

Implementation-authored campaigns and negative mutations are engineering
validation. They are not independent blind acceptance or human play. The parent
breadth/composition issues #493/#495 and human-play gate remain open.
