   owner instructions. Preserve unrelated work. Record source identity once.
3. Inspect the latest user scope, active PR/issue and later approval comments.
   Resume the first unmet condition of authorized work. Do not select a new
   package because an old summary says a prior task was open. If several ready
   tasks compete without a clear direction, progress independent work and ask
   one consequential question. A continuation request grants no new canon or
   automatic merge authority.
4. Read [runtime_delivery_protocol.md](runtime_delivery_protocol.md). Load only
   applicable routes from [source_and_capability_map.md](source_and_capability_map.md).
   Reuse a valid packet; refresh only changed sources.

   issue/PR, not a second authority ledger. Proceed through available authorized
   implementation and verification; report unavailable gates truthfully.
