## Current capability assessment procedure

Use existing contracts, compatibility ledger and live tracker dispositions.
For each affected family record representation, valid generation/configuration,
public execution, qualification, persistent consequences, observed verification,
remaining boundaries and concrete expansion trigger. Keep claims source-bound.
Tarrow provides bounded declared profiles, not universal physics, hydrology,
weather, unrestricted abilities, arbitrary bodies or a complete NPC brain.
Actor PR #549 requires its own live-head check; do not import its unmerged code
into main claims. Canon production status is not executable certification.
