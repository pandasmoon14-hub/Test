## Required evidence

- Structural/local link validation and meaningful tooling failure-path tests.
- Real context capture and focused verification using the new launcher.
- Commands discovered from actual retained CI; no silent report omissions.
- Required complete existing CI plus new platform portability checks at the
  published candidate. Report pending runs as pending; do not wait with repeated
  unchanged model turns once independent work is complete.
- Independent bounded workflow assessment may check the method; it cannot stand
  in for a genuine ordinary-chat run or actual account configuration.

The package cannot ensure identical model capability, tools, throughput or quota
across products. Its objective is portable standards, discoverable knowledge,
complete integration and verifiable continuity. Do not report all 24 measures
fully installed until their external gates have actually been observed.
