instruction is installed, start a genuinely ordinary chat inside the Project.
Send only: “Continue working on the repo.” No skill invocation or master prompt.

Record model/mode, accessible tools, exact repository head, retrieved files and
actual outputs in the owning portability PR. Check that it:
- Retrieves current guidance and identifies the active authorized task.
- Distinguishes implemented behavior, proposals, canon and verification status.
- Resumes a real unmet step without requesting repeated approval for routine work.

- Preserves substantive scope, privacy, persistence, replay and merge gates.
- Leaves unsupported certification pending and emits a compact resumable checkpoint.

Repeat with read-only/no-shell constraints when available. A scripted context
report or same-Work-mode dry run does not establish ordinary-chat acceptance.
